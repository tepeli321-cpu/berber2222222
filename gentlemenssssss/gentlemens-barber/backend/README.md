# Gentlemen's Barber Backend

1. Open Google Apps Script in a new project.
2. Copy the contents of `Code.gs` into the Apps Script editor.
3. Save the project and deploy as a Web App.
4. Use the generated `SCRIPT_URL` in `js/config.js`.
5. The admin password is currently set to `175886963`.

This backend stores appointments in a Google Sheet named `Appointments` and supports:
- login
- list appointments
- add appointment
- delete appointment
